# 医院门诊挂号诊断系统 — 需求规格说明书

## 1. 项目概述

基于 Web 的小型医院门诊挂号诊断系统，支持患者在线预约挂号、医生查看预约记录并标记就诊状态、管理员进行基础配置与数据统计。

---

## 2. 用户角色与权限

### 2.1 患者（Patient）
- 手机号注册 / 登录
- 浏览科室、医生、可预约时段
- 预约挂号（科室 → 医生 → 时间段）
- 取消预约（随时可取消，无限制）
- 查看完整预约历史（待就诊、已就诊、已取消）
- 编辑个人资料（修改姓名、密码）
- 已就诊记录可查看诊断结果和处方详情

### 2.2 医生（Doctor）
- 查看本人的预约列表（患者姓名、联系方式、预约时间段、就诊状态）
- 标记就诊状态：已就诊 / 未到 / 已取消
- 查看患者的完整就诊历史（历史预约、诊断、处方）
- 填写诊断结果和开具处方
- 开具检查检验单，查看检查检验报告
- 管理住院患者（入院申请、住院医嘱、病程记录）
- 编辑个人资料（职称、简介、照片）
- 打印处方单

### 2.3 管理员（Admin）
- 科室管理（增删改查）
- 医生管理（增删改查，含所属科室信息）
- 排班管理（为医生设置出诊日期及时段）
- 检查项目管理（增删改查检查项目，如血常规、CT 等）
- 病房与床位管理（病房号、床位号、所属科室）
- 住院管理（入院登记、出院结算）
- 查看基础预约统计（各科室/医生预约量、预约趋势、取消率）

## 3. 功能需求

### 3.1 注册与登录
- 患者通过手机号 + 短信验证码注册/登录
- 首次注册须填写：手机号、密码、姓名
- 医生和管理员账户由系统预置（管理员后台创建）

### 3.2 患者端 — 挂号流程
1. 选择科室
2. 系统展示该科室下所有医生，并显示医生当前可预约状态
3. 选择医生，进入医生详情页
4. 查看该医生的出诊日历（月视图，显示当月哪些日期有排班）
5. 选择就诊日期（在日历上高亮有排班的日期）
6. 系统展示该医生在该日期的可预约时段（按小时划分，如 8:00-9:00, 9:00-10:00 ...）
7. 选择时段，进入确认页
8. 填写病情描述（选填，如症状、持续时间等）
9. 确认预约信息并提交
10. 预约成功，显示预约详情

> **号源规则**：管理员设置医生的出诊时段，不设号源上限，时段内均可预约。

> **号源不足处理**：若所选医生在某个时段无排班，系统提示无号并推荐同科室其他有号医生。

### 3.3 患者端 — 我的预约
- **待就诊**：展示即将就诊的预约，可取消
- **历史记录**：已就诊 / 已取消的预约列表
- 每条记录包含：科室、医生、就诊日期与时段、预约时间、状态
- 已就诊记录可查看医生的诊断结果和处方详情
- 收到系统通知（预约成功、就诊完成、医生更新诊断等）

### 3.4 患者端 — 取消规则
- 随时可取消，无时间限制
- 取消后号源即时释放（虽然不限号，但确保记录准确）
- 无取消次数限制，无黑名单机制

### 3.5 医生端
- 首页展示当天待就诊的患者列表
- 可按日期筛选查看预约列表
- 列表信息：患者姓名、预约时段、联系电话、病情描述
- 可标记状态：已就诊、未到
- 已就诊后可填写诊断结果和开具处方（药品名称、用量、用法、天数）
- 诊断和处方在就诊后可追加编辑
- 点击患者可查看其完整就诊历史（历史预约记录、既往诊断、处方记录）
- 诊断和处方面板支持一键打印处方单（HTML 打印，格式适合纸质处方）
- 预约状态流转：待就诊 → 已就诊 / 未到（取消由患者主动操作）
- 可编辑个人资料：职称、简介、头像照片
- 收到系统通知（新预约提醒、患者取消预约等）

### 3.6 管理员端 — 科室管理
- 科室名称、科室简介
- 支持启用/停用科室（停用后前端不可见，已有预约不受影响）

### 3.7 管理员端 — 医生管理
- 医生姓名、所属科室、职称、简介
- 支持启用/停用医生

### 3.8 管理员端 — 排班管理
- 为医生设置出诊日期
- 为每个出诊日设置可预约时段（如 8:00-12:00 拆分为 8-9, 9-10, 10-11, 11-12）
- 可批量设置（如每周一至周五固定排班）
- 排班变更不影响已有预约
- 支持查看历史排班记录（已过期的排班分开展示，仅查看不可操作）

### 3.9 管理员端 — 数据统计
- 各科室预约量（按日/周/月）
- 各医生预约量
- 预约趋势图
- 取消率统计

### 3.10 个人资料编辑
- 患者可修改：姓名、密码
- 医生可修改：职称、简介、头像照片（上传）
- 所有修改需先验证原密码
- 手机号不可修改（作为登录凭证）

### 3.12 药品管理
- 系统预设常用药品数据库，按分类组织（抗生素类、感冒用药类、解热镇痛类、消化系统类、心血管类等）
- 医生开处方时，药品名称通过分类下拉选择，方便快捷
- 选择药品后自动填入常用用量和用法，医生可按需调整
- 每种药品包含：所属分类、药品名称、常用用量、常用用法
- 药品数据由系统预置，通过种子数据初始化，不提供 CRUD 界面（后续可扩展）

### 3.13 检查检验模块
- 管理员维护检查项目库（项目名称、所属科室、价格、参考值范围等）
- 检查项目分类：检验类（血常规、尿常规、肝功能等）、影像类（CT、X 光、B 超等）
- 医生在就诊时可开具检查检验单，选择项目并填写临床诊断
- 每个检查单包含多个检查项目
- 检查状态流转：待缴费 → 已缴费 → 执行中 → 已完成
- 检查结果录入：检验科/管理员录入结果（数值、报告文本、图片附件）
- 结果支持上传图片/PDF（如 CT 影像、心电图）
- 已完成的检查结果患者端可查看，医生端在就诊时可查阅
- 检查报告单支持打印

### 3.14 住院管理
- 管理员维护病房与床位：每个病房有床位列表，床位关联所属科室
- 医生在就诊后可申请入院（选择病房类型、填写入院诊断）
- 入院申请审批后分配床位
- 住院患者管理：
  - 每日医嘱（长期医嘱、临时医嘱）
  - 病程记录（医生填写，按时间轴展示）
  - 体温单（每日体温、脉搏、呼吸等）
  - 住院费用记录（药品费、床位费、检查费）
- 出院管理：医生开具出院医嘱，管理员办理出院结算
- 住院状态：在院 / 已出院
- 患者端可查看住院费用明细和每日医嘱

### 3.15 电子病历
- 每位患者拥有完整的电子病历档案
- 病历内容包含：
  - 基本信息（姓名、性别、年龄、联系方式）
  - 过敏史、既往病史、家族病史
  - 历次就诊记录（诊断、处方、检查报告）
  - 住院记录（入院记录、病程记录、出院小结）
- 医生在就诊时可直接查看患者完整病历
- 病历按时间线展示，支持关键字搜索
- 病历数据仅医生和管理员可查看，保护患者隐私

### 3.11 消息通知
- 系统在关键操作后自动生成通知
- **通知触发场景：**
  - 患者预约成功 → 通知医生（新预约）
  - 患者取消预约 → 通知医生（取消提醒）
  - 医生标记已就诊 → 通知患者（就诊完成）
  - 医生更新诊断或开药 → 通知患者（可查看诊断/处方）
- 通知包含：标题、内容、相关链接（点击可跳转到对应页面）
- 通知列表按时间倒序排列，已读/未读状态标记
- 各角色可在顶部导航栏看到未读通知数（小红点标识）
- 点击通知可标记为已读，支持一键全部已读

## 4. 业务规则

| 规则项 | 说明 |
|--------|------|
| 预约时间粒度 | 每小时一个时段 |
| 预约流程 | 科室 → 医生 → 日期 → 时段 |
| 号源上限 | 不限号（管理员仅设时段，不设号源数） |
| 同天多约 | 允许，但须为不同科室 |
| 初诊/复诊 | 不区分 |
| 亲情账户 | 不支持，仅限本人 |
| 就诊卡 | 不绑定 |
| 改签 | 不支持，取消后重新预约 |
| 通知 | 站内信通知（系统自动触发） |
| 黑名单 | 无 |
| 并发控制 | 不涉及（不限号，无抢号冲突） |
| 多院区 | 不支持，单一院区 |
| 支付 | 不涉及 |
| 入院管理 | 医生申请入院，管理员审批分配床位 |
| 检查检验 | 医生开单，管理员/检验科录入结果 |
| 病历 | 每位患者一份完整病历，所有就诊记录自动汇总 |

---

## 5. 预约状态机

```
[待就诊] ── 患者取消 ──→ [已取消]
       │
       ├── 医生标记已就诊 ──→ [已就诊] ──→ 可填写诊断、开药
       │
       └── 医生标记未到  ──→ [未到]
```

## 6. 非功能需求

| 需求项 | 说明 |
|--------|------|
| 系统规模 | 小型，日预约量 < 500 人次 |
| 部署方式 | Web 应用，浏览器访问 |
| 响应时间 | 页面加载 < 2s，操作响应 < 1s |
| 数据安全 | 用户密码加密存储，HTTPS 传输 |
| 浏览器兼容 | 支持主流浏览器最新版本（Chrome、Edge、Firefox） |

## 7.  glossary（术语表）

| 术语 | 说明 |
|------|------|
| 预约 | 患者在系统上选择医生和时段完成挂号的行为 |
| 排班 | 管理员为医生设定的出诊日期及时段安排 |
| 待就诊 | 预约已确认，尚未就诊的状态 |
| 已就诊 | 医生标记患者已完成就诊 |
| 未到 | 患者未在预约时段出现，医生标记为未到 |
| 已取消 | 患者在就诊前主动取消预约 |
| 号源 | 医生在某时段的可预约机会（本系统不限号） |
| 病情描述 | 患者在预约时填写的症状描述（选填） |
| 诊断 | 医生在就诊后填写的诊断结果 |
| 处方 | 医生开具的药品清单，包含药品名称、用量、用法、天数 |
| 药品分类 | 系统预置的药品分类，如抗生素类、感冒用药类等 |
| 药品 | 系统预置的常用药品，包含名称、常用用量、常用用法 |
| 就诊历史 | 患者历次预约、诊断、处方的完整记录 |
| 出诊日历 | 医生的排班日历视图，按月展示出诊日期 |
| 个人资料 | 用户的姓名、密码、职称、简介、头像等基本信息 |
| 通知 | 系统在关键操作后自动生成的站内信消息，包含标题、内容、相关链接 |
| 检查项目 | 医院提供的检查/检验服务，如血常规、CT、X 光等 |
| 检查单 | 医生开具的检查申请单，包含一个或多个检查项目 |
| 病房 | 医院住院部的房间，每个病房有多个床位 |
| 床位 | 病房内的床位，每位住院患者占用一个床位 |
| 入院 | 医生申请患者住院，管理员分配床位的过程 |
| 出院 | 医生开具出院医嘱，管理员办理结算的过程 |
| 医嘱 | 医生对住院患者的治疗指令，分为长期医嘱和临时医嘱 |
| 病程记录 | 医生对住院患者每日病情变化的记录 |
| 病历 | 患者的完整医疗档案，包含基本信息、病史、历次就诊记录 |
| 检查报告 | 检查检验完成后生成的结果报告，包含数值和诊断意见 |

---

## 8. 未纳入范围（明确排除）

- 现场挂号 / 自助机挂号
- 支付 / 退费（住院费用为记录式，不涉及实际支付接口）
- 药房 / 收费等 HIS 系统对接
- 医生排班冲突检测
- 短信 / 邮件通知（仅站内信）
- 多语言 / 国际化
- 移动端 App
- 医保对接
